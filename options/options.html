API Configuration

This extension uses the Gemini API (free tier — no credit card needed). Get your key at aistudio.google.com → Get API Key → Create API key.

Your key is stored locally in your browser and never sent anywhere except the Gemini API.

Cache Management

Summaries are cached per URL so you never call the API twice for the same page. Clear all cached summaries here if you want fresh results.

API keys are stored only in your local browser storage. They are never committed to code or sent to any server other than Gemini.
